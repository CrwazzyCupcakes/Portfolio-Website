# Portfolio Website

A personal portfolio website built with React, TypeScript, and Vite.

## Features
- Elegant serif typography and editorial layout
- Hero section with dynamic quote rotation
- Education timeline with a custom tree-inspired layout
- Responsive sections for About, What I Do, Work, and Contact

## Development
Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## Publishing
1. Commit your changes.
2. Push to your git remote.
3. Deploy to a static host like Vercel, Netlify, or GitHub Pages.
